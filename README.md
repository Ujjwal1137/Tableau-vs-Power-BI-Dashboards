# Tableau-vs-Power-BI-Dashboards
## 📊 Tableau vs Power BI: Dashboard Comparison Project
This project compares Tableau and Power BI by building interactive dashboards on the same movie dataset to analyze and visualize data insights. The goal is to evaluate the strengths and weaknesses of both tools based on usability, features, and performance in real-world dashboard development.

## 📌 Objective
To understand and compare the capabilities of Tableau and Power BI by designing equivalent dashboards, and critically evaluating their user experience and data visualization strengths.

## 🗂 Dataset
Movie dataset containing information such as genres, revenue, ratings, production companies, etc.

## 🛠 Tools Used
* Tableau Public

* Power BI Desktop

## 📁 Project Features
* Built identical dashboards in both Tableau and Power BI using the same dataset

* Created interactive charts (bar charts, pie charts, filters, slicers) for user exploration

Assessed:

  * Ease of use and design flexibility

  * Data modeling and integration

  * Performance and responsiveness

  * Visual storytelling capabilities

## 🔍 Key Insights
* Tableau excels in design flexibility and aesthetics

* Power BI offers stronger data modeling and Microsoft ecosystem integration

* Both tools enable powerful interactivity but serve slightly different user needs
